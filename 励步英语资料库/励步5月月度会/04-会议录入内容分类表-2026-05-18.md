# 励步 5 月月度会内容分类表 — 2026-05-18

## 1. 分类口径

本表严格区分：

| 分类 | 说明 |
|---|---|
| `已决议` | 只收会议录音中已经明确拍板或形成处理方向的内容 |
| `待处理` | 会上谈到，但未谈透、未形成完整共识或方案 |
| `观察线索` | 由会议或材料暴露出的苗头，值得记住，但不能当成结论 |
| `个人提案/述职计划` | 出现在个人材料里，但不等同于组织已决议 |
| `背景信息` | 只用于理解上下文 |

## 7. 本轮修正后的结论

这次月会最需要先做到的，不是“多提炼出多少任务”，而是把不同认知层级分开：

1. **会议上已经形成的组织判断**
2. **会上尚未谈透的议题**
3. **材料中提出但尚未被组织确认的个人方案**
4. **只值得先记下来的观察线索**

只有这四层分清，后面的 `Task` 才不会建立在被我提前加工过的“伪事实”上。
