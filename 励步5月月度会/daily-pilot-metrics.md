# 日常 TDL 助手试点指标

> 试点范围：荆少巍、李珍  
> 记录频率：每天 1 次  
> 目的：判断当前系统是否已经从“可测试”进入“可持续使用”

## 指标口径

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 周活跃用户 | 当周至少创建 1 条 TDL 的管理者人数 | >= 2 |
| TDL 闭环率 | 本周完成数 / 本周创建数 | >= 60% |
| AI 草稿确认率 | 用户点击“确认创建”的草稿数 / AI 生成草稿总数 | >= 70% |
| 日历事件生成率 | 有 `calendar_event_id` 的 active TDL / 全部 active TDL | >= 90% |
| 平均响应时间 | 用户发消息到收到卡片回复的平均时长 | < 5 秒 |
| 用户主动忽略率 | 草稿被点击“忽略”的数量 / 草稿总数 | < 20% |

## 判读规则

- 连续 2 周低于目标：暂停新增功能，优先修体验和识别准确率。
- 连续 2 周达到目标：可以扩大试用范围，或继续推进会议录入试点。
- 如果“平均响应时间”和“日历事件生成率”达标，但“草稿确认率”低，优先查 AI 理解质量。
- 如果“忽略率”高，先抽样看真实对话，不直接猜测原因。
