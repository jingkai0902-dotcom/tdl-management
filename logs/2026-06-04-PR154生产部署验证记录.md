## 五、部署中发现并修复的问题

### 5.1 heredoc 引号问题

`tdl-prod-check.sh` 通过 SSH 双引号包远端命令，Python heredoc 中的双引号会被本地 shell 处理，导致远端 Python 出现 `NameError`。

修复：

1. `runtime_state_path("intake_worker")` 改为单引号。
2. `{"stale_minutes": ...}` 改为单引号 key。

已通过 PR #155 合并。

### 5.2 asyncpg 参数类型问题

PostgreSQL interval 表达式：

```sql
(:stale_minutes || ' minutes')::interval
```

在 asyncpg 下需要 text 参数；传 int 会报：

```text
expected str, got int
```

修复：

```python
{'stale_minutes': str(PROCESSING_STALE_MINUTES)}
```

已通过 PR #156 合并。
