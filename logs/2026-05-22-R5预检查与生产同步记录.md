## 当前判断

R5 当前不应再归因于以下问题：

- backend 未运行。
- Stream bot 未运行。
- intake worker 未安装或未运行。
- pilot metrics timer 未安装或未运行。
- API health 异常。
- 钉钉互动卡模板未配置。
- `DINGTALK_REQUIRE_INTERACTIVE_REMINDER_CARDS` 未开启。

R5 剩余主方向仍是钉钉后台应用入口配置或钉钉工作通知入口能力限制。

下一步应按 `design/28-R5工作通知入口排查清单-2026-05-22.md` 检查钉钉后台，并做真实客户端复测。
